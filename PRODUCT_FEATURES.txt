FlowBench 核心功能与特性清单 (v1.2.18)
=====================================

一、界面设计与交互体验 (UI & Interaction)
----------------------------------------
1. 现代化 Fluent Design 界面
   - 遵循 Windows 11 设计规范，采用圆角 (Rounded Corners)、阴影 (Shadows) 和深度感。
   - 支持"亚克力" (Acrylic) 材质与"云母" (Mica) 材质背景，营造半透明与磨砂玻璃的视觉效果。
   - 提供明亮 (Light) 与深色 (Dark) 两套无缝主题切换。

2. 双语支持 (Bilingual)
   - 原生支持简体中文与 English 双语界面。
   - 可跟随系统语言自动切换，也可在设置中手动选择。

3. 流畅的视觉反馈
   - 所有按钮、卡片均带有平滑的过渡动画与悬停态。
   - 数据图表实时更新，支持交互式缩放与滚动。

4. 安装与卸载程序
   - 安装向导分四步：欢迎页（logo 由光点汇聚、三条色带依次流出组成）→ 选择安装位置（默认位置或自选文件夹，显示所需和可用空间）→ 安装进度（logo 随进度注满）→ 完成（“完成”或“打开 FlowBench”）。
   - 背景是流动的网络波浪动画；右上角的地球按钮切换中文 / English，旁边的按钮切换浅色 / 深色。
   - 软件内“立即更新”使用同样的外观，自动安装并重新打开；卸载程序风格相同，卸载时 logo 逐渐流空。
   - Windows 关闭“动画效果”后，安装和卸载界面不再播放动画。
   - 安装、更新和卸载进度中的固定文字完整显示，仅压缩文件名，空间不足时换行。

二、核心功能模块 (Core Modules)
--------------------------------
1. 压力测试引擎 (Stress Test Engine)
   - **多目标并行测试**：支持同时对多个网站/IP 发起压力测试，实时聚合展示每个目标的状态。
   - **多协议支持**：HTTP、HTTPS、TCP、UDP、ICMP（Ping）。
   - **Rust 原生引擎与 Python 引擎**：本机 HTTP/HTTPS 可使用 Rust，TCP、UDP、ICMP 和插件协议使用 Python；服务器节点的 HTTP/HTTPS/TCP 均支持 Rust。
   - **自动选择与回退**：默认自动使用可启动的原生引擎，否则回退 Python；也可指定必须使用 Rust 或始终使用 Python。授权、目标检查和节点上限在启动引擎前执行。
   - **服务器节点随包引擎**：Windows Agent 内置 Windows Rust 引擎；Linux 节点包带 glibc 2.17 的 x86-64 预编译引擎，ARM/musl 节点在自动模式下使用 Python。
   - **精细控制**：可调节并发线程数、请求速率上限（QPS）、持续时间等参数。
   - **实时统计面板**：
     - 实时 QPS (Queries Per Second) 监控。
     - 成功/失败请求数与实时错误原因分析。
     - 累计发送流量统计（自动换算 B/KB/MB/GB）。
     - 活跃线程数监控。
   - **专业级报告**：测试结束后生成详细报告，包含平均延迟、P50/P90/P99 分位延迟、错误类型分布等。
   - **配置导入/导出**：可将测试配置保存为 JSON 文件，下次直接导入复用。

2. 实时系统监控 (Real-time System Monitor)
   - 实时监控本机 CPU、内存、网络吞吐等性能指标。
   - 可在“监控对象”里切换到服务器节点，查看服务器的 CPU、内存、网络、TCP 连接数和进程数，显示方式与本机相同。
   - 直观的动态折线图与柱状图，支持缩放与历史回溯。

3. 分布式协同测试 (Collaborative Testing)
   - 支持多节点协同发压，模拟更高并发压力。
   - 通过公共 MQTT 中继服务器实现外网协同，无需自建服务器。
   - 邀请码机制快速建立主控-节点连接，支持 5 分钟有效期。
   - “多选服务器”面板每行右侧提供红色“删除”按钮；工具栏按“全选”“清空”“删除”（红色）“恢复已删除”排列，工具栏删除当前面板全部勾选的服务器，包括被搜索隐藏的勾选项。全部删除后仍可打开面板恢复。删除记录按本机控制地址和令牌分别保存，刷新、重启后仍生效，并同步移除监控列表中的服务器。
   - 删除只影响本机列表，服务器 Agent 和已有任务继续运行；需要停止任务时先使用“停止服务器任务”。

4. 授权与合规 (Authorization & Compliance)
   - 内置授权确认机制，所有目标需经过用户授权方可测试，确保合法合规。
   - 内置速率与流量保护机制，防止误操作。
   - 服务器节点有各自的上限（每秒请求数、单个任务时长、线程数），生成节点时可以设置；发送任务前先按上限检查，
     超出时可以按各节点的上限运行，节点拒绝任务时会显示原因。

三、实用工具与功能 (Utilities)
-------------------------------
1. 自动检查更新 (Auto Update)
   - 启动时静默检查 GitHub Releases。
   - 发现新版本时弹窗提示；安装版点“立即更新”会在软件内下载新版安装包（带进度条、校验文件），
     自动关闭软件、完成更新并重新打开。下载失败时可以改用浏览器从发布页下载。

2. 审计日志 (Audit Logging)
   - 完整记录所有压测操作历史，支持导出为文本文件，便于复盘与审计。

3. 应用设置 (Settings)
   - 个性化配置：主题、语言、默认测试参数（线程数、超时、速率等）。
   - 本机压测引擎：自动（推荐）、原生引擎（Rust）、Python 引擎，显示原生引擎查找状态，从下一次 HTTP/HTTPS 压测生效；服务器节点由各自的 agent.json 独立配置。
   - 偏好备份、恢复备份和恢复默认均包含压测引擎选择。
   - 关于页面：显示版本信息、免责声明、作者主页链接。

四、技术亮点 (Technical Highlights)
----------------------------------
- 基于 Python + PySide6 (Qt) 构建，性能与跨平台兼顾。
- 独立 Rust 原生压测进程与 Python 工作线程，通过版本化 JSON 协议传递任务、实时统计和报告。
- 两套引擎统一限速、重定向、代理、超时和成功判定；原生引擎随控制进程退出而停止，异常退出保留最后一次统计。
- 数据本地持久化，重启后自动恢复上次测试配置。
- 公共 MQTT 中继实现零配置外网协同测试。
